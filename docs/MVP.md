# MVP Scope

## Минимальный функционал для презентации

- Регистрация и логин (email + JWT)
- Загрузка документа (PDF, DOCX, TXT)
- Оплата через Stripe (test mode)
- Перевод документа через очередь
- Нотаризация: кабинет нотариуса + подпись
- Скачивание готового документа
- Всё работает в Kubernetes (k3s на VDS)
- Публичный доступ через Cloudflare Tunnel

## Что НЕ входит в MVP

- Мобильное приложение
- Поддержка множества языков (достаточно EN/RU)
- Production Stripe (только test mode)
- Автоматическая нотаризация без человека
